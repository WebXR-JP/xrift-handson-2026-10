# XRift ハンズオン

XRift Studioを使って、歩いて回れる3Dワールドを作るハンズオン資料です。

[ハンズオン資料を見る](./slides.md)

## 作るもの

小道とベンチ、目印のある小さな休憩広場を作ります。物を置き、色をつけ、ワールドの中を歩いて完成を確かめます。形や色は自由に変えられます。

## はじめる前に

- [XRift](https://xrift.net/)のアカウント
- [XRift Studio](https://webxr-jp.github.io/xrift-studio/#download)を使えるパソコン

資料の最初から、アカウントの作成とXRift Studioの準備を順番に案内します。すでに準備ができている場合は、ワールド制作から始められます。

操作に困ったら、[XRift Studioの使い方](https://github.com/WebXR-JP/xrift-studio/blob/main/docs/guide/index.md)もご覧ください。
